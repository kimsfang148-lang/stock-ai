# Stock AI Pro — Complete Local AI Edition

Windows + Python 3.14 + Streamlit 기반의 모듈형 주식 분석 앱입니다.

## 기본 원칙
- 기본 AI: **Ollama 로컬 AI** (OpenAI API 비용 없음)
- OpenAI API: 선택사항
- 계정/관심종목: PC 내부 SQLite 저장
- 분석 결과: Streamlit 재실행 후에도 세션 동안 유지
- 한국 주식: KRW(₩), 미국 주식: USD($) 표시

## 주요 기능
- 현재가 / 차트 / MA20·60·200 / RSI / MACD / Bollinger
- 과거 수익률, CAGR, 변동성, MDD, Sharpe
- 단기/중기/장기 참고점수
- 모델 참고 적정가치 + Bear/Base/Bull 시나리오
- 백테스트 + Walk-forward
- 위험 기준 포지션 크기 계산
- 미국 SEC / 한국 DART 연동 모듈
- 뉴스 / 기본 경쟁사 비교
- 시장 스캐너 / 후보 순위 / CSV 리포트
- 로컬 Ollama AI 종합분석
- 공용 웹용 무료 규칙 기반 분석 (외부 AI API 비용 0원)
- 사용자 본인 Gemini API 키를 선택적으로 세션에서 사용 (운영자 키 미사용)
- 선택적 OpenAI AI 분석
- 로컬 회원가입 / 로그인 / 로그아웃
- 계정별 관심종목 저장
- 연결 진단 도구

## 실행
1. ZIP을 새 폴더에 압축 해제합니다.
2. `run_stock_ai.bat`을 더블클릭합니다.
3. 브라우저에서 Stock AI Pro가 열립니다.

Python 3.14가 설치되어 있어야 합니다. `run_stock_ai.bat`은 `.venv`를 만들고 의존성을 설치합니다.

## 무료 AI
Ollama가 설치되어 있고 모델이 준비되어 있으면 사이드바에서 `무료 로컬 AI (Ollama)`를 선택합니다.

기본 모델은 `qwen3.5:4b`입니다. Ollama 모델 저장 위치를 D 드라이브로 설정한 경우 기존 모델을 그대로 사용할 수 있습니다.

`setup_local_ai.bat`은 모델 다운로드를 도와주는 선택적 도구입니다. 이미 모델이 설치되어 있다면 다시 실행할 필요가 없습니다.

## 공용 웹 AI 비용 정책
공개 배포에서는 **운영자 소유의 Gemini/OpenAI API 키를 사용하지 않습니다.** 따라서 운영자가 사용자 AI 호출 비용을 대신 부담하지 않는 구조입니다.

### 사용자 본인 Gemini API 키 연결
1. 사이드바 `🤖 AI 설정`에서 `사용자 본인 Gemini API`를 선택합니다.
2. 본인의 Gemini API 키를 입력합니다.
3. `AI 종합분석`, 뉴스/공시 AI 분석, 상위 50종목 AI 비교 등을 실행합니다.
4. 키는 현재 Streamlit 세션에서만 사용하며 계정 DB와 GitHub에 저장하지 않습니다. `🗑️ Gemini 키 지우기`로 즉시 세션 상태에서 지울 수 있습니다.

**중요:** Streamlit 서버에서 Gemini API를 호출하므로 입력한 키는 AI 요청을 위해 서버로 전달됩니다. 이 앱은 키를 DB/GitHub에 저장하지 않지만, 공용 서버 운영자에게 키가 기술적으로 완전히 비공개인 구조는 아닙니다. 운영자에게도 키가 보이지 않아야 한다면 브라우저에서 Gemini API를 직접 호출하는 별도 프런트엔드 구조가 필요합니다.

Google의 현재 Gemini API 문서 기준으로 Free Tier가 제공되며, 무료 한도와 모델별 제한은 Google 계정/프로젝트 및 선택 모델에 따라 달라집니다. 유료 프로젝트/유료 키를 연결하면 해당 키의 과금 정책이 적용될 수 있으므로 사용자가 자신의 Google AI Studio/Cloud 설정에서 확인해야 합니다.

기본 사용자 Gemini 모델은 `gemini-2.5-flash-lite`입니다. `GEMINI_MODEL` 환경변수로 변경할 수 있습니다.

## OpenAI 선택사항
`.env`에 `OPENAI_API_KEY`와 유효한 `OPENAI_MODEL`을 설정하면 화면에서 OpenAI를 선택할 수 있습니다. 기본값은 로컬 AI입니다.

## 계정
왼쪽 `👤 계정`에서:
- 게스트 사용
- 로그인
- 회원가입
- 관심종목 저장
을 할 수 있습니다.

계정 데이터는 `data/stock_ai_accounts.db`에 저장됩니다. 이 인증 기능은 **로컬 PC용**이며 인터넷 공개 서비스용 인증 시스템이 아닙니다.

## DART
한국 종목은 `005930`처럼 6자리 코드 또는 `005930.KS`를 입력할 수 있습니다. DART 재무/공시는 `DART_API_KEY`가 필요합니다.

## SEC
미국 종목은 `NVDA`, `AAPL` 같은 티커를 입력합니다. SEC 접근에는 식별 가능한 `SEC_USER_AGENT`를 설정하는 것이 좋습니다.

## 스캐너
현재 예시 유니버스를 대상으로 합니다. 거래소 전체 종목 스캔을 하려면 최신 종목 마스터와 적절한 시장데이터 공급원을 추가해야 합니다.

## 주의
적정가치, 점수, 백테스트, AI 분석은 참고용입니다. 미래 수익을 보장하지 않습니다. 실서비스로 확장할 때 실시간 데이터 라이선스, 슬리피지, 수수료, 배당/분할, 룩어헤드 바이어스, 생존자 편향 등을 별도로 검증해야 합니다.

## 포트폴리오
로그인한 회원은 `💼 내 포트폴리오`에서 보유 종목을 저장할 수 있습니다.
- 종목코드 / 시장(KR·US)
- 보유 주식수(소수점 가능)
- 평균 매수가
- 현재가
- 투자금 / 평가금액
- 평가손익 / 수익률
- 보유종목 수정·삭제

포트폴리오는 기존 로컬 SQLite 계정 DB에 함께 저장됩니다. 한국(KRW)과 미국(USD) 포트폴리오는 환율을 임의 적용해 합산하지 않고 각각 표시합니다.


## 이번 업데이트
- 1분/5분/10분/15분/30분/1시간/일봉 차트 간격 선택
- 10분봉은 5분봉 데이터를 리샘플링
- 최신 뉴스/SEC/DART 공시 AI 이벤트 분석
- 시장 스캐너에서 후보가 없는 이유를 데이터/점수 기준별로 표시

## v4 업데이트
- 차트 간격: 1분/5분/10분/15분/30분/1시간/사용자 지정 1~60분/일봉
- 10분 및 사용자 지정 분봉은 원천 분봉 데이터를 리샘플링
- 최신 뉴스/공시 이벤트 AI 분석
- 이벤트 감시에서 최신 뉴스·공시를 한 번에 확인/분석
- 시장 스캐너에서 후보가 없는 원인을 데이터 없음/계산 실패/점수 기준으로 표시

## 기존 계좌/포트폴리오 데이터 이어받기
v5는 처음 실행할 때 현재 폴더에 계좌 DB가 없으면 주변의 이전 Stock AI Pro 폴더에서 `data/stock_ai_accounts.db`를 찾아 한 번만 복사합니다. 기존 v5 DB가 있으면 절대 덮어쓰지 않습니다. 따라서 v4를 삭제하기 전에 v5에서 기존 계좌와 포트폴리오가 보이는지 확인하세요.

## 차트 간격/데이터 기간 사용자 입력
- 차트 간격: 숫자 + 초/분/시간/일/개월/년
- 데이터 기간: 숫자 + 초/분/시간/일/개월/년
- 예: `30분봉 + 6개월`, `2시간봉 + 3년`, `5분봉 + 3일`
- 초 단위 원천 주가가 제공되지 않는 경우 가장 가까운 1분 데이터를 사용합니다.

## 웹사이트 형태로 배포
`Dockerfile`, `.streamlit/config.toml`, `DEPLOY_WEB.md`를 포함해 서버 배포가 가능하도록 구성했습니다. 로컬에서는 `http://localhost:8501`, 공개 서버에 배포하면 해당 서버가 발급한 `https://...` 주소로 접속할 수 있습니다.
